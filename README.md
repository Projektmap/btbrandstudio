# BT Brand Studio

Generátor brand konceptu (název, logo, paleta, písmo, tón komunikace, ukázky použití) podle oboru, barevnosti a charakteru.

- `index.html` – aplikace
- `api/brand.js` – volá Claude API; na Vercelu nastavte `ANTHROPIC_API_KEY`, doporučeně `BRAND_KOD` (přístupový kód), volitelně `MODEL` (výchozí claude-sonnet-5-5)
